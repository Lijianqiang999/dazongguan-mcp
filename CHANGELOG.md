# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- Initial release of MCP Server Template
- MCP Python SDK 2.0 support
- ApiKey authentication middleware
- Example tools (search, detail, create, update, delete)
- Comprehensive documentation (English and Chinese)
- Environment variable configuration
- Logging with file rotation
- MIT License
- Contributing guidelines

### Features
- Modular tool system for easy extension
- Async API calls with httpx
- Error handling and response validation
- Resource support for read-only data
- Production-ready configuration

## [0.1.0] - 2024-01-XX

### Added
- Initial project structure
- Basic MCP server implementation
- Configuration system
- Middleware framework
